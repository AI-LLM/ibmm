IBIS Diagram Generator

Notation Guide:
• Roman numerals (I, II, III...) = Issues
• Roman.Roman (I.I, I.II...) = Sub-issues
• Roman+Number (I1, II2...) = Positions (solutions)
• +Number = Pros (arguments for)
• -Number = Cons (arguments against)
• Use commas for multiple connections (e.g., "I1,II1 Shared solution")

Auto-numbering: Use shortcuts like "I1+" or "I1-" and the system will automatically add the next available number (e.g., "I1+1", "I1-2")
